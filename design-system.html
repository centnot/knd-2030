Правило: чем больше значение — тем темнее градиент. Максимум — #2563EB → #1D4ED8, минимум — #93C5FD → #60A5FA.

Градиенты НЕ используются для нод SVG, карточек, фонов секций или кнопок. Единственное исключение — SVG linearGradient sd-core (#DBEAFE → #BFDBFE) для фона центрального rect архитектурной схемы.

Правила цветовой иерархии

ПРИНЦИПЫ
  • Белый = первый план. Карточки, hero, основной контент — всегда белый
  • Цвет = сигнал, не декор. Каждый цвет несёт смысл (система, статус, эмоция)
  • border-left = принадлежность. Синий = АСУ КНД/ОИ, amber = УБР, красный = риск
  • Насыщенность = важность. #2563EB (кнопки) > #60A5FA (числа) > #93C5FD (обводки) > #DBEAFE (фон)
  • Фон = 50-уровень. Семантические подложки: самый светлый оттенок палитры
  • Тёмные = SVG-ноды. #0F172A-#64748B только для fill нод-источников на схемах
  • 1 акцент на блок. Не смешивать синий + зелёный + amber в одном challenge-block
ЗАПРЕЩЕНО
  • Цветной текст на цветном фоне (кроме white на #2563EB)
  • Градиенты для нод, карточек, кнопок, фонов секций
  • Оттенки красного (#E11D48, #BE123C) для не-проблемных блоков
  • border-left разных цветов в одной карточке
  • Больше 3 семантических цветов на одной странице print
  • Прозрачность (opacity) на тексте — только на SVG-связях
  • Цвет #E94E1B (оранжевый РвР) — на сайте НЕ используется, только в палитре бренда

13. Принципы дизайн-системы

Flat Design

Без градиентов, без глубоких теней. Белые поверхности + тонкие границы #D6DFEC. Hover: граница синеет #BFD4FF, тень усиливается.

Цветовая иерархия

Акцент #2F5EFF — для заголовков, метрик, CTA. Серые — для нейтрального контента. Семантические (red/green/amber) — только для статусов.

Типографическая плотность

Отрицательный letter-spacing на заголовках (-0.03em). Body — 1.6 line-height. Контраст весов: 800 vs 400.

Адаптивность

Breakpoints: 1024px (2 колонки), 768px (компактнее), 600px (1 колонка), 480px (минимум). Print: A4 landscape.

14.13 Правила построения схем

DO
  • Один центральный объект крупнее остальных
  • Направление потока: слева → направо, сверху → вниз
  • Qudratic Bézier для связей между уровнями
  • Анимация только для активных потоков данных
  • Цвет стрелки = цвет источника, не приёмника
  • Числа в нодах — крупнее текста (12-14 / 800)
  • Разделители-линии для зонирования внутри rect
  • Badge-circle для номеров пунктов ТЗ / ТР
  • Подпись-hint внизу: «наведите на систему...»
  • Статусные зоны (warning) — внутри или снизу центра
DON'T
  • Больше 3 уровней глубины на одной схеме
  • Пересекающиеся стрелки без обоснования
  • Анимация на плановых / пунктирных связях
  • Фиксированные размеры без min-width
  • Больше 6 цветов маркеров на одной схеме
  • Текст мельче 8px (нечитаем при print)
  • Inline style на SVG без display:block
  • Использовать ёж вместо ✋ для ручных разрывов
  • Градиенты для нод (только для фона центра)
  • Забыть font-family: Inter на <svg>
